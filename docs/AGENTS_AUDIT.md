# Проверка каркаса по AGENTS.md

Проверена актуальная ветка `origin/main` репозитория `ibaimao/Diploma`, коммит `5d84c1f` (`Add files via upload`). Корневой `AGENTS.md` прочитан полностью и сохранён без изменений.

## Причина первоначальной ошибки

Первый каркас создавался в локальной копии на коммите `cb3badb`, где был только README.md. Перед утверждением, что AGENTS.md отсутствует, не был выполнен `git fetch origin main`. Это было упущением проверки актуальности репозитория; отсутствие файла в локальной копии не означало его отсутствия в main.

## Сохранность работы и main

- До переключения веток README и все 27 созданных файлов сохранены в локальную резервную копию с SHA-256-манифестом в игнорируемой папке `work/before-main-sync`.
- В актуальном main по сравнению с исходной локальной копией добавлен только `AGENTS.md`; README в main не менялся.
- Рабочая ветка `codex/study-planner-scaffold` создана от `origin/main`. Сразу после переключения проверено побайтовое совпадение всех 28 файлов с резервной копией.
- Исходные 27 файлов не удаляются. Для исправлений меняются документация и настройки тестирования; добавлены этот отчёт и сохраняемый в Git набор тестов. Исходники интерфейса сохранены.
- В main изменения напрямую не записываются; работа подготовлена для Pull Request. Внесённый владельцем `AGENTS.md` в PR не изменяется.
