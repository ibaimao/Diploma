# Планировщик для учёбы

Веб-приложение для студентов с задачами, будущим автоматическим планированием, календарём, Pomodoro, учётом времени и виртуальным 3D-питомцем.

**Текущий этап: работа с задачами и сохранение в браузере.** Можно создавать, редактировать, удалять и завершать задачи. Дата и время — локальные текущие. Питомец остаётся SVG-иллюстрацией-заглушкой; аккаунтов и 3D пока нет.

## Быстрый запуск

Нужны Node.js **24 LTS** и npm, входящий в его состав. В терминале в папке с `package.json`:

```sh
npm ci
npm run dev
```

Откройте Local URL из терминала (обычно <http://localhost:5173/>). Остановка — `Ctrl+C`.

**Новичкам на Windows:** подробная инструкция установки инструментов, открытия проекта, запуска и решения частых ошибок находится в [docs/WINDOWS_SETUP.md](docs/WINDOWS_SETUP.md).

## Что доступно

- Компоновка по предоставленным референсам: кремовые фоны, голубая панель, пастельные задачи, тёплая комната.
- На компьютере: боковая навигация, задачи слева и комната справа.
- Приложение занимает `100vw` × `100dvh` без внешних полей, скруглений и тени. На компьютере сохраняются голубая область слева и комната справа; светлая панель немного выступает за голубую на стыке с комнатой.
- На телефоне: комната сверху занимает около 38% высоты, задачи — оставшееся место, навигация — отдельную нижнюю строку с учётом safe area. Прокрутка разрешена только внутри панели задач.
- SVG масштабируется равномерно. Для телефона используется отдельный `viewBox` с `meet`, сохраняющий котика целиком; фон расширен за границы сцены, чтобы не появлялись пустые полосы.
- Карточки сохраняют существующие цвета и оформление. Нажатие на название открывает редактирование; отметка справа переключает выполнение.
- Разделы: «Задачи на день», «Календарь», «Таймер Pomodoro», «Задания за монетки», «Магазин предметов». Работает только переключение экранов-заглушек, без реализации будущих функций.
- Новые элементы управления: выбор дня, «Сегодня», кнопка «+» и модальное окно задачи в существующей палитре. Компоновка, навигация и пропорции комнаты сохранены.
- Отдельные компоненты иллюстрации и контейнера питомца для будущей замены на 3D.
- Локальный рукописный шрифт Neucha и иконки Lucide; внешние ключи и `.env` не требуются.

## Согласованный стек

Сейчас используются **React + TypeScript + Vite**. По мере разработки добавятся **Supabase Auth + PostgreSQL**, бесплатные компоненты **FullCalendar**, алгоритм планирования на **TypeScript** и **Blender → GLB → React Three Fiber / Drei**. Для размещения выбран **Cloudflare Pages**; публикация пока не выполнялась.

Все основные функции планирования и синхронизация должны оставаться бесплатными для пользователей. Базовый питомец и базовая кастомизация также бесплатны. Будущая монетизация ограничена необязательной косметикой питомца. Платежи, платные функции и награды в текущем прототипе отсутствуют.

## Как пользоваться задачами

1. Нажмите «+», введите название, часы/минуты, дату и время дедлайна. Категория необязательна; выберите один из четырёх существующих цветов.
2. Нажмите название карточки, чтобы изменить поля или удалить задачу. Удаление требует отдельного подтверждения; «Отмена» сохраняет задачу.
3. Нажмите отметку справа, чтобы завершить задачу; повторное нажатие отменяет выполнение.
4. Выберите день над списком: задачи относятся к дню **дедлайна**, поскольку распределения по рабочим слотам пока нет. «Сегодня» возвращает текущий день и автоматически следует за сменой суток.
5. Незавершённые задачи с истёкшим дедлайном показаны отдельно, независимо от выбранного дня. Выполненные остаются на дне своего дедлайна. Чтобы увидеть старую выполненную задачу, выберите её день.
6. Обновите страницу, закройте и снова откройте браузер по тому же адресу: задачи сохраняются. После удаления всех задач список остаётся пустым; демонстрационные примеры не загружаются.

Данные находятся в localStorage данного браузера и адреса сайта (`study-planner.tasks.v1`). Другой браузер, профиль, порт или устройство имеет отдельное хранилище. Очистка данных сайта удалит задачи; приватный режим может удалять их при закрытии. При недоступном/переполненном хранилище или повреждённых данных показывается ошибка, приложение не выдаёт несохранённое изменение за успешное и не заменяет данные примерами.

Предполагаемая длительность хранится в `estimated_minutes`, фактическая — отдельно в `actual_minutes` (пока 0, учёт сессий не реализован). Дедлайн хранится как момент времени UTC, вводится и отображается в локальном часовом поясе пользователя.

## Изменения через Pull Request

Работа ведётся в отдельной ветке `feat/task-management`. После изменений выполните `npm test`, `npm run typecheck`, `npm run build`, затем создайте коммит и отправьте эту ветку (`git push -u origin feat/task-management`). На GitHub откройте Pull Request из неё в `main`, изучите вкладку Files changed и результаты проверок. Слияние выполняется отдельно после проверки; напрямую в `main` изменения не отправляются.
