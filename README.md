# Планировщик для учёбы

Веб-приложение для студентов с задачами, будущим автоматическим планированием, календарём, Pomodoro, учётом времени и виртуальным 3D-питомцем.

**Текущий этап: адаптивный интерфейс-прототип.** Все задачи, расписание и дата 1 сентября — демонстрационные. Питомец — SVG-иллюстрация-заглушка. Создания задач, сохранения, аккаунтов и 3D пока нет.

## Быстрый запуск

Нужны Node.js **24 LTS** и npm, входящий в его состав. В терминале в папке с `package.json`:

```sh
npm ci
npm run dev
```

Откройте Local URL из терминала (обычно <http://localhost:5173/>). Остановка — `Ctrl+C`.

**Новичкам на Windows:** подробная инструкция установки инструментов, открытия проекта, запуска и решения частых ошибок находится в [docs/WINDOWS_SETUP.md](docs/WINDOWS_SETUP.md).

## Что доступно

- Компоновка по предоставленным референсам: кремовые фоны, голубая панель, пастельные задачи, тёплая комната.
- На компьютере: боковая навигация, задачи слева и комната справа.
- Приложение занимает `100vw` × `100dvh` без внешних полей, скруглений и тени. На компьютере сохраняются голубая область слева и комната справа; светлая панель немного выступает за голубую на стыке с комнатой.
- На телефоне: комната сверху занимает около 38% высоты, задачи — оставшееся место, навигация — отдельную нижнюю строку с учётом safe area. Прокрутка разрешена только внутри панели задач.
- SVG масштабируется равномерно. Для телефона используется отдельный `viewBox` с `meet`, сохраняющий котика целиком; фон расширен за границы сцены, чтобы не появлялись пустые полосы.
- Однострочные карточки, подписи и время из макета; отметки справа статические, исходно все пустые, как на референсе.
- Разделы: «Задачи на день», «Календарь», «Таймер Pomodoro», «Задания за монетки», «Магазин предметов». Работает только переключение экранов-заглушек, без реализации будущих функций.
- Дополнительных видимых слоганов, шапки и поясняющих карточек нет. Демонстрационный режим и отсутствие функций обозначены в заголовке вкладки и доступных описаниях для вспомогательных технологий.
- Отдельные компоненты иллюстрации и контейнера питомца для будущей замены на 3D.
- Локальный рукописный шрифт Neucha и иконки Lucide; внешние ключи и `.env` не требуются.

## Согласованный стек

Сейчас используются **React + TypeScript + Vite**. По мере разработки добавятся **Supabase Auth + PostgreSQL**, бесплатные компоненты **FullCalendar**, алгоритм планирования на **TypeScript** и **Blender → GLB → React Three Fiber / Drei**. Для размещения выбран **Cloudflare Pages**; публикация пока не выполнялась.

Все основные функции планирования и синхронизация должны оставаться бесплатными для пользователей. Базовый питомец и базовая кастомизация также бесплатны. Будущая монетизация ограничена необязательной косметикой питомца. Платежи, платные функции и награды в текущем прототипе отсутствуют.
