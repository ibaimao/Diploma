# Планировщик для учёбы

Веб-приложение для студентов с задачами, будущим автоматическим планированием, календарём, Pomodoro, учётом времени и виртуальным 3D-питомцем.

**Текущий этап: работа с задачами и сохранение в браузере.** Можно создавать, редактировать, удалять и завершать задачи. Дата и время — локальные текущие. Питомец остаётся SVG-иллюстрацией-заглушкой; аккаунтов и 3D пока нет.

## Быстрый запуск

Нужны Node.js **24 LTS** и npm, входящий в его состав. В терминале в папке с `package.json`:

```sh
npm ci
npm run dev
```

Откройте Local URL из терминала (обычно <http://localhost:5173/>). Остановка — `Ctrl+C`.

**Новичкам на Windows:** подробная инструкция установки инструментов, открытия проекта, запуска и решения частых ошибок находится в [docs/WINDOWS_SETUP.md](docs/WINDOWS_SETUP.md).

## Что доступно

- Компоновка по предоставленным референсам: кремовые фоны, голубая панель, пастельные задачи, тёплая комната.
- На компьютере: боковая навигация, задачи слева и комната справа.
- Приложение занимает `100vw` × `100dvh` без внешних полей, скруглений и тени. На компьютере сохраняются голубая область слева и комната справа; светлая панель немного выступает за голубую на стыке с комнатой.
- На телефоне: комната сверху занимает около 38% высоты, задачи — оставшееся место, навигация — отдельную нижнюю строку с учётом safe area. Прокрутка разрешена только внутри панели задач.
- SVG масштабируется равномерно. Для телефона используется отдельный `viewBox` с `meet`, сохраняющий котика целиком; фон расширен за границы сцены, чтобы не появлялись пустые полосы.
- Карточки сохраняют существующие цвета и оформление. Нажатие на название открывает редактирование; отметка справа переключает выполнение.
- Разделы: «Задачи на день», «Календарь», «Таймер Pomodoro», «Задания за монетки», «Магазин предметов». Работает только переключение экранов-заглушек, без реализации будущих функций.
- «Задачи на день» показывает только сегодня: быстрое добавление кнопкой «+», необязательные время и длительность, цвет по приоритету. Компоновка, навигация и пропорции комнаты сохранены.
- Отдельные компоненты иллюстрации и контейнера питомца для будущей замены на 3D.
- Локальный рукописный шрифт Neucha и иконки Lucide; внешние ключи и `.env` не требуются.

## Согласованный стек

Сейчас используются **React + TypeScript + Vite**. По мере разработки добавятся **Supabase Auth + PostgreSQL**, бесплатные компоненты **FullCalendar**, алгоритм планирования на **TypeScript** и **Blender → GLB → React Three Fiber / Drei**. Для размещения выбран **Cloudflare Pages**; публикация пока не выполнялась.

Все основные функции планирования и синхронизация должны оставаться бесплатными для пользователей. Базовый питомец и базовая кастомизация также бесплатны. Будущая монетизация ограничена необязательной косметикой питомца. Платежи, платные функции и награды в текущем прототипе отсутствуют.

## Как пользоваться задачами

1. Нажмите «+» и введите название; категория необязательна. Задача добавится на сегодня без длительности и дедлайна. Включите нужные тумблеры, чтобы указать часы/минуты и время завершения сегодня.
2. Нажмите название карточки для редактирования. Здесь доступен расширенный набор полей: дата дела, приоритет, необязательные длительность и дедлайн. Дедлайн без точного времени означает конец выбранного местного дня. Выключение тумблера очищает соответствующее значение при сохранении.
3. Цвет определяется приоритетом: высокий — коралловый, средний — персиковый, низкий — шалфейный, без приоритета — голубой. Быстрая задача создаётся без приоритета.
4. Нажмите отметку справа: задача зачёркивается, становится менее яркой и перемещается вниз. Повторное нажатие отменяет выполнение. Монеты не начисляются.
5. Порядок: невыполненные сегодня → невыполненные просроченные → выполненные сегодня. Пустой раздел просроченных скрыт. Прошлые/будущие даты нельзя просматривать на дневной вкладке; их задачи остаются в хранилище для будущего календаря.
6. Красный крестик или Escape закрывает форму без сохранения. Зелёная кнопка сохраняет. Удаление доступно при редактировании и требует подтверждения; можно вернуться к задаче или закрыть форму.
7. Обновите страницу: задачи и их статусы сохраняются. Подробная проверка, модель и подключение расширенной формы описаны в [docs/TASKS_V2.md](docs/TASKS_V2.md).

Данные находятся в localStorage данного браузера и адреса сайта (`study-planner.tasks.v2`). При первом запуске старые записи из `study-planner.tasks.v1` безопасно преобразуются; исходный ключ сохраняется как резервная копия. Существующий v2 (в том числе пустой список) имеет приоритет, поэтому удалённые задачи не восстанавливаются из копии. При ошибке чтения или записи приложение сообщает о ней и не заменяет данные примерами. Другой браузер, профиль, порт или устройство имеет отдельное хранилище.

Дата дела (`planned_date`), дедлайн (`deadline`), оценка (`estimated_minutes`, число минут или `null`), приоритет и выполнение разделены. Фактическое время `actual_minutes` не подменяется оценкой. `schedule_blocks` зарезервирован для будущих рабочих интервалов, автопланирования сейчас нет.

## Изменения через Pull Request

Текущая ветка — `feat/task-forms-and-priorities`, созданная поверх `feat/task-management` (предыдущий PR №2 ещё не в `main`). Новый PR сравнивается с `feat/task-management`, чтобы показывать только этот этап. После слияния №2 в `main` перенаправьте новый PR на `main` и проверьте разницу. Прямых коммитов в `main` нет.

Перед отправкой новых изменений выполните `npm test`, `npm run typecheck`, `npm run build`, затем создайте коммит и отправьте свою ветку. Слияние выполняется отдельно после проверки.
